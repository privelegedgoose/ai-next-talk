# AI NEXT talk: AI automation in companies

Web version of the slides for the talk "AI automation in companies: how to build AI systems that save money" (AI NEXT, 19 November 2026), by Daria Gavrilova, HCD Barcelona.

- `index.html` is the whole deck in one file (fonts embedded). Arrow keys, space or the dots on the right move between slides.
- `img/` holds the screenshots and photos used on the slides. The demo screenshots show sample data and a fictional client.
- `src/` holds the slide markup and the extra styles the page was built from.

The money figures on the slides are an illustrative model, not measured company records.

Search engines are asked not to index this page (the `robots` meta tag in `index.html`). If you rebuild `index.html` from `src/`, add that tag again.
